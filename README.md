# SmartBudgetManager
A project for managing budjet
================================================================================

SMARTBUDGET MANAGER (SmartBudget_Manager.xlsx)

================================================================================



1. OVERVIEW

--------------------------------------------------------------------------------

SmartBudget Manager is a simple, ready-to-use Microsoft Excel workbook designed 

to help individuals and small teams track their personal or monthly finances. 

It automates budget calculations, categorizes spending, visualizes financial 

data, and alerts you when you exceed your monthly spending limit.



Key Features:

* Record monthly income and daily expenses in one centralized table.

* Categorize expenses using predefined categories (Food, Transport, Rent, etc.).

* Automatically calculate total income, total expenses, and monthly balance.

* View visual charts breaking down expenses by category.

* Receive automatic visual warnings (color highlights) if your budget limit 

  is exceeded.



2. SYSTEM REQUIREMENTS & PREREQUISITES

--------------------------------------------------------------------------------

To open and use SmartBudget Manager properly, you need:

* Software: Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent 

  compatible spreadsheet application (e.g., LibreOffice Calc).

* Hardware: Any standard Windows or macOS computer capable of running Excel.

* Skills: Basic spreadsheet navigation (selecting cells, typing data, and 

  using drop-down menus). No advanced formula knowledge is required.



3. WORKBOOK STRUCTURE

--------------------------------------------------------------------------------

The file contains three main worksheets (tabs located at the bottom):

* [Dashboard]    : The main overview screen displaying your monthly balance, 

                   total income, total expenses, budget alerts, and charts.

* [Transactions] : The data-entry log where you record all incoming funds 

                   and outgoing expenses.

* [Categories]   : The reference list containing predefined expense categories.



4. QUICK START GUIDE

--------------------------------------------------------------------------------

Follow these steps to begin tracking your budget:



Step 1: Open the File

  Double-click "SmartBudget_Manager.xlsx" to open it in Excel. If prompted by 

  a yellow security banner at the top, click "Enable Editing".



Step 2: Save a Personal Copy

  Go to File > Save As and save a copy for the current month (e.g., 

  "SmartBudget_November_2026.xlsx") to preserve your blank template.



Step 3: Set Your Budget Limit

  Navigate to the [Dashboard] tab and enter your maximum monthly spending 

  limit in the designated budget cell.



Step 4: Record Income & Expenses

  Switch to the [Transactions] tab. On the first empty row, enter the Date, 

  Description, Category (choose from the drop-down list), and the Amount in 

  either the Income or Expense column.



Step 5: Review Your Dashboard

  Return to the [Dashboard] tab. Your totals, remaining balance, and category 

  charts update automatically. Watch for red/warning highlights indicating 

  overspending.



5. IMPORTANT USAGE NOTES

--------------------------------------------------------------------------------

* Do NOT delete or overwrite cells containing formulas on the [Dashboard] tab 

  (such as SUM or SUMIF calculations).

* Always select categories from the drop-down menu on the [Transactions] tab 

  to ensure the category charts calculate accurately.
